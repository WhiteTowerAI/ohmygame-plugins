## 第 1 代暴露的问题

- 漏查已有能力：PixelLab 骨骼/帧动画、CCGS 的 engine-reference 和各种 skill、内置 Check pixel art 多图比较、发布对话框体积信息、预览内置设备、Game Tests 的 snapshot/画面/控制台检查 → 第 2 代起每个候选必须列出"已核对过的相关已有能力"及文件路径。
- 宿主带 ffmpeg 但没开放给插件。

## 未覆盖的高频痛点（评审指出）

1. 国内小游戏激励视频/插屏/分享接入与规则检查：E72、E74、E75、E76
2. 玩家侧回放、剪辑、分享与主播模式：E8、E9、E54
3. 试玩招募：E21、E24
4. 同一玩法多变体的快速原型对比：E13、E20
5. 英文化/本地化与文字溢出检查：E55、E36

## 来自游戏线的需求（gen-1-games-review 的能力缺口）

Steamworks 发布（7 个游戏候选需要）、西方门户 SDK + 广告规则检查、Discord/YouTube Playables/Telegram 打包、多人语音、麦克风输入模拟、批量无头模拟与平衡面板、微信好友/群共享状态、4MB 主包预算、竖屏广告片段管线、"同类游戏查重"。
