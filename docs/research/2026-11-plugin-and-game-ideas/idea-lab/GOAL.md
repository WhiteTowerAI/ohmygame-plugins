# 目标

从真实需求出发，产出两份经过多轮筛选的清单：

1. **插件想法**：OhMyGame 最值得做的插件，帮人把游戏做出来、做好、发出去。
2. **独立游戏想法**：适合 1–3 人、用 OhMyGame（AI 写代码、生成美术和音频、试玩、发布）做出来的独立游戏。

不为好玩而好玩，不为凑数量而产出。每个想法必须能回答：**谁、在什么时候、遇到什么问题、有什么数据证明这个问题真实存在且常见**。

## 完成标准（全部满足才停）

- 插件终选 6–10 个，游戏终选 6–10 个。
- 每个终选想法至少引用 **2 条**证据（`EVIDENCE.md` 里的编号），其中至少 1 条是数据（调查比例、市场数字、样本统计），不能只靠轶事。
- 每个终选想法都经过对抗评审，没有未解决的**致命问题**（需求不真实、和已有插件或内置功能重复、现有 API 做不出来且没写清缺口、市场已饱和而没有差异）。
- 连续两代前 5 名没有变化（收敛），或者已经跑满 4 代。
- 终选想法写清楚第一步怎么做（插件：用哪些扩展点、MVP 范围；游戏：核心循环、为什么适合 AI 生产、最小可玩版本、发在哪个平台）。

## 不做

- 没有证据的"酷点子"。
- 和 OhMyGame 已有插件或内置功能重复的东西（见 `CONTEXT.md`）。
- 为了覆盖每个扩展点而硬凑的插件。
