## 高频痛点索引（按出现频率和严重度排序）

1. **发现性与营销：供给过剩，没人看见**。证据最多，商业影响最大。E1–E11、E60、E70、E86、E87、E90
2. **做不完：范围失控、低估工作量、动机和时间不够**。E12–E20、E89
3. **设计愿景不清、"不好玩"，且难以提前验证**。E13、E14、E42、E44
4. **试玩难：招不到人，录不下来，分析不过来，反馈稀缺**。E21–E24、E26、E36（47% 用 AI 做试玩/平衡）、E38
5. **AI agent 测不了运行中的游戏，还会误报"完美运行"**（物理、实时类尤甚）。E41、E42、E44
6. **包体和加载时间直接吃掉转化率**。E53、E56、E62、E65、E66、E82
7. **多门户/多平台 SDK 适配与合规**（广告事件、存档、相对路径、外部请求、审核）。E51、E52、E55–E59、E62–E64、E81–E83
8. **移动端浏览器的坑**：竖屏、安全区、iOS 内存与 WebGL 崩溃、音频解锁、存档被清。E54、E56、E66–E68
9. **美术和音频的技能缺口与外包依赖**。E15、E31、E33
10. **AI 素材不一致**：像素网格、帧动画、3D 拓扑与绑定；动画是最大缺口。E32、E42、E45、E46
11. **技术硬骨头**：碰撞/物理、着色器、动画/绑定、分辨率与 UI 缩放、iOS 导出。E27–E29、E13
12. **多人联机**：需求高、难得到帮助、跨设备体验难统一。E28、E30、E49、E63
13. **AI 代码库腐化与引擎版本混淆**（功能越加越乱，Godot 3/4 混用）。E42、E43、E37（模型质量 53%）
14. **AI 的声誉、披露和版权风险**（开发者负面情绪上升，"AI slop" 和不原创被列为驳回理由）。E35、E36、E39、E40、E47、E48、E55、E63、E87
