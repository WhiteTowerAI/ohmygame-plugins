# Plugin and game ideas from developer pain points (2026-11)

Research behind the next official plugins, and a shortlist of indie game ideas
that OhMyGame could be used to make. Written in Chinese.

- [`idea-lab/FINAL.md`](idea-lab/FINAL.md): the result. 5 plugin finalists and 6 game candidates, with
  evidence, first steps, validation plans and what was rejected and why.
- [`reports/游戏开发真实痛点调研.md`](reports/游戏开发真实痛点调研.md): the research report on game developers' pain points.
- [`research_notes/`](research_notes): the six research tracks it was written from.
- [`idea-lab/`](idea-lab): the evidence base (`EVIDENCE.md`, E1–E148), the goal and scoring
  rubric, and every generation's proposals and independent reviews.
- [`idea-lab/experiments/overflow-sort/`](idea-lab/experiments/overflow-sort): the solver experiment for the
  overflow water-sort rule. Raw `results-*.jsonl` are left out; `run.py` regenerates them from fixed seeds.
- [`idea-lab/BUILD-PLAN.md`](idea-lab/BUILD-PLAN.md): what is being built first.
