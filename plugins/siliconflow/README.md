# SiliconFlow

Adds SiliconFlow to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api.siliconflow.com/v1`
- API key: From cloud.siliconflow.com → API Keys. Its accounts are apart from SiliconFlow CN's.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/siliconflow` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
