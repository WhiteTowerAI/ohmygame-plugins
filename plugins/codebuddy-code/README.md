# CodeBuddy Code

Adds CodeBuddy Code to Settings → Agents, beside Claude Code and Codex. Install it, sign in by running `codebuddy`, then turn it on in Settings → Agents; OhMyGame reads its models from the agent.

| Command | Sign in | Install |
| --- | --- | --- |
| `codebuddy --acp` | `codebuddy` | [www.codebuddy.ai](https://www.codebuddy.ai/docs/cli/installation) |

It speaks the [Agent Client Protocol](https://agentclientprotocol.com). It's off
until it's turned on in Settings → Agents; OhMyGame runs only `--version` before
that.

The logo belongs to its maker and is from [LobeHub Icons](https://github.com/lobehub/lobe-icons)
(MIT), as OhMyGame's built-in agents' are. OhMyGame shows it from plugin API
2.5.0; older versions show a terminal mark.

Published as `@ohmygame/codebuddy-code` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
