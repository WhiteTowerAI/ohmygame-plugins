# StepFun

Adds StepFun to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api.stepfun.com/v1`
- API key: From platform.stepfun.com → API Keys.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/stepfun` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
