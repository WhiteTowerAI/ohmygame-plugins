# Hyper3D

Generate 3D models from text or up to five reference images with Rodin. Texture an existing GLB using a reference image and an optional prompt.

Enter your Hyper3D API key in the plugin settings. Generation and texturing use your Hyper3D credits.

[Hyper3D API documentation](https://docs.hyper3d.ai/en/api-specification/rodin-gen2-5)
