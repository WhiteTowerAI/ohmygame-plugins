# TapTap H5 上传与发布

使用独立测试游戏和厂商账号；不要用正式线上游戏做上传或提审实验。

1. 启用 TapTap 插件，在已有网页项目的「发布 → 在 TapTap 管理…」打开面板。
   不应改变项目类型、网页预览或启动 Maker；Maker 插件仍可独立使用。
2. 检查 CLI 未安装、未登录和已登录三种状态。登录通过官方 CLI 浏览器授权；
   面板不要求 token。加载厂商，搜索并翻页选择游戏，连接后重开面板应保留目标。
3. 完成网页生产构建，从自动发现的目录中选择构建及横/竖屏，点击「检查并上传」。
   预览应显示目标、大小和警告；无构建时可手动填写项目内目录。根目录缺少 index.html、
   符号链接、.env、包体被修改应明确拒绝；未确认不能上传。
4. 确认上传一次，隐藏面板后再打开，检查原任务结果。同一意图不能重复上传；
   中途关闭宿主后应显示结果待核对，读回原任务，不盲目重传。声明 H5 但能力冲突时，
   资料仍可查看，上传及绑定不可用，不能自动改游戏类型。
5. 直接修改名称、简介、分类或开发者的话，核对同步预览。刷新、切换分类、重开面板后
   未保存内容应保留。保存后从 CLI 或后台读回；模拟远端字段变化与部分保存时，不应
   覆盖新值或丢失未完成的编辑。图片从项目网格选取，核对规格、上传回执与完整元数据；
   上传只入素材库，保存才应用到字段。移除截图只改本地草稿，放弃操作可恢复。
6. 在包体库点击「用于当前草稿」，核对目标、主槽位快照和最终绑定。缺草稿、候选未就绪、
   快照过期均应停止，不得使用 Windows/Spark 槽。查看版本分页、审核及定时状态；
   面板保存和绑定不能调用提审或发布。提审通过单独的 Agent 命令发起。
7. 在中文/英文、明暗主题和窄面板中检查控件名称、键盘焦点、长路径换行和滚动。
   查询、准备和上传期间不应丢失输入、切换目标或因隐藏视图取消任务。

记录本地打包、CLI dry-run、真实上传、绑定、提审和实际上线各自的验证结果。
只有本地或模拟检查时，不得记录为已经真实发布。
