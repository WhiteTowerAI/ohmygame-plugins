# Novita AI

Adds Novita AI to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api.novita.ai/openai/v1`
- API key: From novita.ai → Settings → Key Management.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/novita` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
