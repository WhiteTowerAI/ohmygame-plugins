# SambaNova

Adds SambaNova to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api.sambanova.ai/v1`
- API key: From cloud.sambanova.ai → APIs.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/sambanova` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
