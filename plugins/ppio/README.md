# PPIO

Adds PPIO to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api.ppinfra.com/v3/openai`
- API key: From ppio.com → Settings → API Keys.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/ppio` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
