# Baidu Qianfan

Adds Baidu Qianfan to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://qianfan.baidubce.com/v2`
- API key: An API key from the Baidu AI Cloud console → Qianfan → API Key (starts with bce-v3/).

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/qianfan` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
