# DeepInfra

Adds DeepInfra to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api.deepinfra.com/v1/openai`
- API key: From deepinfra.com → Dashboard → API Keys.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/deepinfra` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
