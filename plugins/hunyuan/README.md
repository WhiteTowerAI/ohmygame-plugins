# Tencent Hunyuan

Adds Tencent Hunyuan to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api.hunyuan.cloud.tencent.com/v1`
- API key: From the Tencent Cloud console → Hunyuan → API Key.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/hunyuan` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
