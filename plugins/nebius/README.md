# Nebius Token Factory

Adds Nebius Token Factory to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api.tokenfactory.nebius.com/v1`
- API key: From tokenfactory.nebius.com → API Keys.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/nebius` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
