# ModelScope

Adds ModelScope to OhMyGame's Settings → Providers, with your own API key.

- Base URL: `https://api-inference.modelscope.cn/v1`
- API key: Your access token from modelscope.cn → Account → Access Token. It has a free daily quota once an Alibaba Cloud account is linked.

Enter the key on the plugin's page or in Settings → Providers. Models are read
from the provider's `/models`, so new ones appear by themselves.

Published as `@ohmygame/modelscope` from [ohmygame-plugins](https://github.com/WhiteTowerAI/ohmygame-plugins).
